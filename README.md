#  AI Text Generation App

##  Project Overview

AI Text Generation App is a simple text generation application built using **Python, Streamlit, and Hugging Face Transformers**.

The application allows users to enter a prompt and generate meaningful text using a Hugging Face language model. The model runs locally on the computer, so **no Hugging Face API token or API key is required**.

---

##  Objectives

- To build a simple AI text generation application.
- To understand how Hugging Face Transformers can be used with Python.
- To create an interactive user interface using Streamlit.
- To generate text from user-provided prompts.
- To run the language model locally without using an API token.

---

## Technologies Used

- **Python**
- **Streamlit**
- **Hugging Face Transformers**
- **PyTorch**
- **SmolLM2-360M-Instruct**

---

##  Features

- Simple and user-friendly interface
- Text prompt input
- AI-generated text output
- Maximum token control
- Temperature control
- Hugging Face model integration
- Local model execution
- No Hugging Face API token required
- No external API key required
